# AiBrush Media engine

> Scope: This page owns the `@aibrush/media` adapter, its declared support, operation dispatch, normalization, error translation, lifecycle, and vendor-integration boundary; shared runner and oracle mechanics belong to their subsystem pages.
> Phase-2 owner: p2_engine_aibrush_media.

## Purpose

The AiBrush Media engine is a scored browser-media [adapter](../glossary.md) that translates the benchmark's common `MediaEngine` contract into `@aibrush/media` calls. This page tells maintainers which combinations the adapter advertises, what it actually forwards, which observations it normalizes, and where a concrete request becomes `NA_ENGINE`, `FAIL`, or `ERROR`.

Readers changing the shared boundary should also consult the [engine-adapter contract](../subsystems/engine-adapter-contract.md), [runner and capability negotiation](../subsystems/runner-capability-negotiation.md), and [oracle system](../subsystems/oracle-system.md). Feature-specific expectations remain on the corresponding feature pages.

- The adapter uses registry alias `aibrush-media` and result id `aibrush-media@dev`, and each cell must receive a fresh engine instance. ## Target design and known gaps

### Target design

1. **Make applicability tuple-aware at the adapter boundary.** Keep the shared token gate as a cheap first pass, then validate `operation × input container × input codec × output container × output codec × options` before doing costly work. Use exact framework error classes/codes where available, and throw `NotApplicableError` for a runtime inability rather than relying on message regexes. Browser codec support should use the concrete WebCodecs configuration: the specification defines `isConfigSupported()` for exactly that purpose and does not guarantee that any codec is present.[W3C WebCodecs, codec configuration support](https://www.w3.org/TR/webcodecs/#config-support) Acceptance: table-driven tests cover at least still-image demux/remux, fragmented trim, append-only output, PCM/container legality, HEVC browser re-import, and unsupported encode tuples; every unsupported tuple produces `NA_ENGINE`, while malformed media and genuine implementation faults retain their distinct paths.

2. **Report semantic correctness separately from legal representation.** Introduce the shared `PASS` / `DIFF` / `FAIL` oracle verdicts: `PASS` for a normalized semantic match, `DIFF` for a valid representation that differs from the ffmpeg-baked golden, and `FAIL` only for wrong or unusable output. For packets, compare decode order/timestamps, sync semantics, decodability, and required codec configuration rather than demanding the baker's exact byte size, keyframe placement, or grouping. The AVC WebCodecs registration defines encoded chunks as access units and permits either length-prefixed AVC with configuration out of band or Annex B with parameter sets in-band; those forms can legitimately change size and grouping.[W3C AVC WebCodecs Registration, encoded data](https://w3c.github.io/webcodecs/avc_codec_registration.html#encoded-data) HEVC has the analogous distinction between `hevc` length-prefixed data and Annex B byte streams.[W3C HEVC WebCodecs Registration, encoded data](https://w3c.github.io/webcodecs/hevc_codec_registration.html#encoded-data) Acceptance: two decodable outputs that differ only by Annex B versus AVCC/hvcC-style framing, inline SPS/PPS/VPS, or legal NAL grouping yield `DIFF`, not `FAIL`; damaged timestamps, missing access units, or undecodable required output still yield `FAIL`.

3. **Keep quality reference decoding neutral, but pair frames by media time.** The source side should remain the unscored browser WebCodecs reference; that separation is fair because WebCodecs exposes codec primitives without making the candidate engine its own judge.[W3C WebCodecs, abstract](https://www.w3.org/TR/webcodecs/#abstract) Pair source and output frames by timestamp within an explicit timebase/cadence tolerance, not array index, so intentional fps or frame-count changes do not shift every subsequent comparison. Record output validity/re-import separately from reference decoder applicability: a valid file that the current browser cannot decode is `NA_BROWSER` for that reference observation, not proof that AiBrush produced invalid media. Acceptance: fps-changing outputs align by presentation time, and a browser missing a supported output decoder cannot manufacture an engine `FAIL`.

4. **Preserve observed metadata and normalize equivalence in the oracle.** The adapter should keep truthful observed rates/channels and must not fabricate ffprobe's representation. The golden-metadata comparator must match tracks by media type rather than index and canonicalize `avc1` / `avc3` / `V_MPEG4/ISO/AVC` to `h264`, `hev1` / `hvc1` to `hevc`, and `mp4a` to `aac`. It must accept an HE-AAC/SBR core rate versus a reconstructed 2× rate and a Parametric Stereo one-channel core versus two-channel output: the WebCodecs AAC registration identifies `mp4a.40.5` as HE-AAC v1 with SBR and `mp4a.40.29` as HE-AAC v2 with SBR plus Parametric Stereo, while ETSI's HE-AAC description shows both the 2× synthesis rate and mono-to-stereo Parametric Stereo reconstruction.[W3C AAC WebCodecs Registration, codec strings](https://www.w3.org/TR/webcodecs-aac-codec-registration/#fully-qualified-codec-strings) [ETSI TS 102 005 V1.2.1, HE-AAC v2 decoder](https://www.etsi.org/deliver/etsi_TS/102000_102099/102005/01.02.01_60/ts_102005v010201p.pdf) Compare VFR and NTSC fps in a documented band rather than by rounded equality; Apple's format guidance distinguishes the exact `30000/1001` cadence from `29.97`.[Apple TN2162, QuickTime image rates](https://developer.apple.com/library/archive/technotes/tn2162/_index.html) Widen duration tolerance for edit-list presentation mapping, AAC priming, and timebase rounding; Apple's format documentation shows that edit-list media time and track duration select the presented region and that differing movie/media timebases may not be sample-accurate.[Apple QuickTime File Format, representing encoder delay](https://developer.apple.com/documentation/quicktime-file-format/using_track_structures_to_represent_encode_delay_explictly) Acceptance: equivalent core/output HE-AAC observations, reordered same-type tracks, rational-rate representations, and documented presentation-timeline shifts do not fail this engine, while missing tracks and materially wrong program duration still do.

5. **Make cancellation and ownership single-source.** Give every adapter operation the runner's abort signal/deadline, ensure its deadline cannot outlive the cell, await termination before final status, and remove process-global error suppression. Assign each `VideoFrame`, `AudioData`, reader, and pooled decoder exactly one closer. WebCodecs requires callers to release the underlying media resource via `close()` and notes that resources should be released immediately.[W3C WebCodecs, `VideoFrame.close()`](https://www.w3.org/TR/webcodecs/#dom-videoframe-close) Acceptance: a forced 120-second timeout aborts framework work before cell teardown; an unhandled rejection from the next engine remains visible; instrumented frame handles are closed exactly once on success, rejection, and abort.

6. **Make telemetry and provenance factual per operation.** Retain callback-write telemetry for genuine stream targets, label buffer materialization separately, and report peak retained bytes so a callback stream that is later concatenated cannot be presented as constant-memory output. Populate `configUsed` from the actual framework route/driver selected for the operation and record the exact AiBrush source revision, dirty state, package version, build flags, and WASM artifact digest in run metadata. Package managers distinguish local path dependencies from immutable registry or commit-addressed dependencies; npm's package-spec rules support Git commit-ish pinning for reproducible source selection.[npm package-spec, Git URLs and local paths](https://docs.npmjs.com/cli/v11/using-npm/package-spec) Acceptance: rerunning the same revision produces the same provenance tuple, and reports can distinguish callback writes, buffer synthesis, and full-output retention.

### Known gaps

#### Coarse declarations leak unsupported combinations into execution

**Current.** The capability object advertises flat, undirected codec/container/feature sets, while concrete legality is discovered in scattered operation branches or translated from framework exceptions.[src/engines/aibrush-media/adapter.ts:3752-3900](../../src/engines/aibrush-media/adapter.ts#L3752-L3900) [src/engines/aibrush-media/adapter.ts:4075-4093](../../src/engines/aibrush-media/adapter.ts#L4075-L4093) **Consequence.** A token-complete scenario can enter the adapter and become `ERROR` if a framework miss does not match the broad translator, creating pressure to add disabled cells. **Target.** Add deterministic tuple preflight and typed `NotApplicableError` translation, consistent with WebCodecs' configuration-specific support model.[W3C WebCodecs, codec configuration support](https://www.w3.org/TR/webcodecs/#config-support) **Verification.** Generate the cross-product of declared operations, directions, containers, codecs, and meaningful options; unsupported rows must terminate as `NA_ENGINE` before mutation or output allocation.

#### Advertised option semantics are not always forwarded

**Current.** `fragmented` is advertised, but trim forwards only range, mode, and sink; the runner's trim-option projection likewise omits a fragmentation request.[src/engines/aibrush-media/adapter.ts:3840-3863](../../src/engines/aibrush-media/adapter.ts#L3840-L3863) [src/engines/aibrush-media/adapter.ts:4294-4343](../../src/engines/aibrush-media/adapter.ts#L4294-L4343) [src/core/runner.ts:750-765](../../src/core/runner.ts#L750-L765) `fastStart:reserve` is collapsed to a boolean, and the callback target rejects non-contiguous positioned writes.[src/engines/aibrush-media/adapter.ts:1746-1777](../../src/engines/aibrush-media/adapter.ts#L1746-L1777) [src/engines/aibrush-media/adapter.ts:3041-3047](../../src/engines/aibrush-media/adapter.ts#L3041-L3047) [src/engines/aibrush-media/adapter.ts:5248-5274](../../src/engines/aibrush-media/adapter.ts#L5248-L5274) **Consequence.** The gate can claim a requested output organization that the adapter did not request or cannot express. **Target.** Forward and observe the exact mode, or reject the tuple as `NA_ENGINE`; ISO BMFF layout claims must be verified from the produced box/timeline structure rather than inferred from a truthy flag. The MSE ISO BMFF byte-stream profile makes the relevant structure observable by defining an initialization segment as `ftyp` followed by `moov` and distinguishing fragment-bearing initialization.[W3C, ISO BMFF Byte Stream Format](https://www.w3.org/TR/mse-byte-stream-format-isobmff/#initialization-segments) **Verification.** Re-import trim/fast-start outputs and assert the required fragmentation or front-loaded metadata organization; unsupported positioned-write modes must never report support.

#### Packet goldens encode the baker's representation

**Current.** The adapter returns framework packetization faithfully, but `golden-packets` requires positional packet count, exact size, and keyframe equality.[src/engines/aibrush-media/adapter.ts:626-784](../../src/engines/aibrush-media/adapter.ts#L626-L784) [src/core/oracles.ts:835-927](../../src/core/oracles.ts#L835-L927) **Consequence.** Annex B versus length-prefixed framing, inline SPS/PPS/VPS, and legal access-unit/NAL grouping can make valid AiBrush output fail. **Target.** Make semantic packet validity `PASS`, valid representation divergence `DIFF`, and actual corruption `FAIL`, following the AVC and HEVC encoded-data registrations.[W3C AVC WebCodecs Registration, encoded data](https://w3c.github.io/webcodecs/avc_codec_registration.html#encoded-data) [W3C HEVC WebCodecs Registration, encoded data](https://w3c.github.io/webcodecs/hevc_codec_registration.html#encoded-data) **Verification.** Repacketize one valid sample between supported forms without changing decoded content; the verdict must be `DIFF` and retain a precise representation diagnostic.

#### Timeouts and global error handling cross cell boundaries

**Current.** The runner gives up at 120 seconds without aborting, the adapter waits 310 seconds before aborting, and the global safety net remains armed for two seconds after disposal.[src/core/runner.ts:670-683](../../src/core/runner.ts#L670-L683) [src/engines/aibrush-media/adapter.ts:180-292](../../src/engines/aibrush-media/adapter.ts#L180-L292) **Consequence.** Framework work may continue after a recorded result, and a late rejection from another cell can be suppressed. **Target.** Propagate one cell-scoped AbortSignal, await cleanup, and contain errors to adapter-owned promises; AbortController is specifically the platform mechanism for communicating abort to asynchronous operations.[WHATWG DOM, AbortController](https://dom.spec.whatwg.org/#interface-abortcontroller) **Verification.** A deliberately stalled operation leaves no readers, decoder queues, timers, or listeners after timeout, and a sentinel rejection immediately after teardown reaches the harness.

#### Resource ownership and route telemetry are ambiguous
