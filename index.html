How it works

① Functional — is it correct?

Each engine's output is checked by library-independent oracles: golden metadata & packet tables, bit-exact decoded frames, SSIM/PSNR for lossy ops, and re-import with the reference engine. Correctness is the gate — a number only counts if the output is right.

② Performance — how fast, how cheap?

Headline throughput & cost, measured in-page over warmup + iterations: ops/s, packets/s, frames/s, wall ms, ×RT (realtime), peak memory, long-task time, and min+gzip bundle size.

③ Robustness — does it fail gracefully?

Malformed and mutated inputs must reject or throw within a timeout — never crash, hang, or OOM — and metamorphic invariants must hold across equivalent transforms.
